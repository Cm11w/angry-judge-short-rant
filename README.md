# Angry Judge: The Short Rant Contest

Entry for the [Angry Judge: The Short Rant Contest](https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046) on make.fun — a short, funny rant about an everyday annoyance, judged head-to-head by a furious AI judge.

## The rant

> I bought one sandwich. The self-checkout scanned it, weighed it, then screamed 'UNEXPECTED ITEM IN THE BAGGING AREA' like I'd smuggled a piano into the store. I froze. A teenager strolled over, pressed one button, and undid in two seconds what the machine spent a full minute accusing me of. We fired every cashier and replaced them with a robot that calls security on a ham sandwich.

384 characters, 384 bytes, no trailing newline.

## Why this rant

The judge weighs, in order: a funny rant about an everyday annoyance, actual funniness, a specific concrete annoyance, sharp economical wording, and freshness. This entry picks the self-checkout's "unexpected item in the bagging area" — a concrete, universally shared humiliation — instead of the brief's own overused examples (printer, bus, Monday morning). It escalates absurdly (a sandwich treated like a smuggled piano), lands a concrete image (a teenager undoing in two seconds what the machine spent a minute accusing me of), and closes on the punchline: a robot that calls security on a ham sandwich. Four sentences, every one earning its place, and short enough that the size tie-break works in its favour.

## How it works

`main.ts` (Node 22, no dependencies) writes the rant to `/output/entry.txt`. The gate requires UTF-8 text of 1–400 characters; the file is exactly the rant, with no trailing newline. Run it locally with `OUTPUT_DIR=/tmp/out node main.ts` to test; in the grading sandbox it writes to `/output` by default.
